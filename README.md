# Tonvana

Professional Piano Tuning & Instrument Care

## About

Tonvana is a professional piano tuning and instrument care service based in Winnipeg, Canada.

Services include:

- Piano Tuning
- Piano Regulation
- Instrument Repair
- Preventive Maintenance

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

## Development

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Open:

http://localhost:3000
